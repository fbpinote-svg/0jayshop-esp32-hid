# ESP32-S3 Real HID Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rework ESP32-S3 Max HID firmware into a durable, low-latency real USB keyboard and mouse device for Sunshine.

**Architecture:** Use three USB HID interfaces: dedicated keyboard, dedicated relative mouse, and vendor HID for Sunshine packets/ACK. Keep the 64-byte Sunshine vendor protocol stable while letting keyboard and mouse reports send independently in the same 1 ms loop.

**Tech Stack:** ESP32-S3, ESP-IDF 5.4.0 via PlatformIO `espressif32@6.10.0`, `esp_tinyusb`, TinyUSB HID device API, Python static protocol tests.

---

## File Structure

- Modify `src/main.c`: descriptors, interface constants, packet validation, state machine, independent keyboard/mouse/vendor sending.
- Modify `tests/check_protocol.py`: static contract tests for three interfaces, ACK independence, packet validation, no hot-path allocation/logging.
- Keep `tools/esp32s3_hid_protocol.py`: host packet helper remains wire-compatible.
- Keep `platformio.ini` and `sdkconfig.defaults`: current ESP-IDF/TinyUSB stack already matches the design.

static bool packet_valid(const uint8_t raw[VENDOR_REPORT_BYTES]) {
  return raw[0] == RID_VENDOR && raw[16] == crc8(raw, 16);
}

static void add_saturated(int32_t *dst, int32_t delta, int32_t min_value, int32_t max_value) {
  int64_t next = (int64_t)*dst + delta;
  if (next > max_value) next = max_value;
  if (next < min_value) next = min_value;
  *dst = (int32_t)next;
}

### Task 4: Send Mouse, Keyboard, And ACK Independently Per Tick

**Files:**
- Modify: `src/main.c`
- Test: `tests/check_protocol.py`

- [ ] **Step 1: Replace `hid_loop()` send selection**

Inside `hid_loop()`, use separate readiness flags:

```c
    const bool kbd_ready = tud_hid_n_ready(IFACE_KEYBOARD);
    const bool mouse_ready = tud_hid_n_ready(IFACE_MOUSE);
    const bool vendor_ready = tud_hid_n_ready(IFACE_VENDOR);
```

Inside the critical section, set all send flags independently:

```c
    send_ack = st.ack_dirty && vendor_ready;
    if (send_ack) {
      ack[0] = st.ack_seq;
      ack[1] = 0x01;
      ack[2] = FW_PROTOCOL;
      ack[3] = FW_MAJOR;
      ack[4] = FW_MINOR;
      ack[5] = FW_PATCH;
      st.ack_dirty = false;
    }

    send_mouse = mouse_ready && (st.mouse_dirty || st.dx || st.dy || st.wheel);
    if (send_mouse) {
      mouse.buttons = st.buttons;
      mouse.x = take16(&st.dx);
      mouse.y = take16(&st.dy);
      mouse.wheel = take8(&st.wheel);
      st.mouse_dirty = st.dx || st.dy || st.wheel;
    }

    send_kbd = kbd_ready && st.kbd_dirty;
    if (send_kbd) {
      kbd = st.kbd;
      st.kbd_dirty = false;
    }
```

After unlocking, send each available report:

```c
    if (send_ack) tud_hid_n_report(IFACE_VENDOR, RID_VENDOR, ack, sizeof(ack));
    if (send_mouse) tud_hid_n_report(IFACE_MOUSE, 0, &mouse, sizeof(mouse));
    if (send_kbd) tud_hid_n_report(IFACE_KEYBOARD, 0, &kbd, sizeof(kbd));
```
